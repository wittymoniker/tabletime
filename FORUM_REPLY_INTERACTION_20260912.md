# Comment interaction update — 2026-09-14

- `Comment` is the only reply action shown on posts, forums, groups, events, and messages.
- The old `Reply as message`, `Reply as post`, `Reply as group`, `Reply as event`, and similar controls are removed.
- A comment appends directly to the target post's Comments field and notifies the target owner when appropriate.
- New messages are composed explicitly from the Messages page. Message remains a private communication mode, not a post-reply type.
- Historical reply-tagged posts remain readable and sortable for compatibility; no new reply-as-* records are created by the normal UI.
