# Post-cell expand / minimize

Post cards can now be expanded by clicking a non-interactive area of the post cell.

- First click: the selected post spans the full post grid for easier reading.
- Second click: the post returns to its normal grid cell.
- Links, buttons, form controls, comments disclosure, media controls, and editable elements do not trigger expansion.
- Selecting text does not trigger expansion.
- Existing comment wrapping and Comments-link styling remain intact.
